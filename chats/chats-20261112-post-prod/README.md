This dir
`chats-20261112-post-prod`
contains some exports of chats with AI.

Any raw JSON files were
obtained from AI companies' APIs.
This [custom app](https://github.com/paveljee/chat-viewer) is
used to convert a raw JSON file into a Markdown file.
This project uses some Tampermonkey exporter scripts –
thanks to their authors:
[Claude API Exporter 5.6.0 by MRL](https://update.greasyfork.org/scripts/542117/Claude%20API%20Exporter.user.js) and
[ChatGPT Exporter 2.32.0 by pionxzh](https://update.greasyfork.org/scripts/456055/ChatGPT%20Exporter.user.js).
