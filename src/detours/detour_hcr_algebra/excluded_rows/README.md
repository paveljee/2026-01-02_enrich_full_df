# HCR award rows matching excluded names

Generated by `excluded_rows.py`.

`population_with_names_economy` is the Step 4 view joining `population` (Clarivate XLSX award rows loaded in Step 2), `population_names` (normalized column names derived in Step 3), and `population_economy` (Step 4 economy and priority fields). This detour reads it read-only.

The first query uses Step 6's exact null/empty-name predicate on all award rows; Step 6's persisted exclusion archive covers sampled rows only. The second query matches each distinct excluded-name token group to award rows whose compact names contain every token, regardless of order. `unaccent` is a session-local alias for `strip_accents`. The templates below expand the named SQL snippets before execution.

### Excluded award rows

list_filter(list_transform(regexp_split_to_array(trim(regexp_replace(lower(unaccent(COALESCE(COALESCE(p."ktp.first_name", '') || ' ' || COALESCE(p."ktp.last_name", ''), ''))), '[[:punct:][:space:]]+', ' ', 'g')), '\s+'), token -> trim(token)), token -> token <> '')

-- tokens_sql
list_sort(list_distinct({normalized_tokens_sql}))

-- excluded_name_condition_sql(first, last)

    OR p."ktp.last_name" IS NULL

    OR p."ktp.last_name" = ''

       p."ktp.hcr_row_number", p."ktp.first_name", p."ktp.last_name",
       {tokens_sql} AS excluded_name_tokens
FROM population_with_names_economy p

### Matching award rows

```sql
-- docx_name_norm_sql(name)
regexp_replace(lower(unaccent(COALESCE(p."ktp.first_name", '') || ' ' || COALESCE(p."ktp.last_name", ''))), '[^0-9a-z]+', '', 'g')

-- match_sql template
WITH excluded_award_rows AS (
    {exclusion_sql}
),
token_groups AS (
    SELECT DISTINCT excluded_name_tokens
    FROM excluded_award_rows
)
SELECT g.excluded_name_tokens, p.*, n.candidate_name_norm
FROM token_groups g
CROSS JOIN population_with_names_economy p
CROSS JOIN LATERAL (
    SELECT {docx_name_norm_sql} AS candidate_name_norm
) n
WHERE list_bool_and(
    list_transform(
        g.excluded_name_tokens,
        token -> strpos(n.candidate_name_norm, token) > 0
    )
)
ORDER BY p."ktp.population_index"
```
